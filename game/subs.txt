# Functions reimplemented in C, with their original C calling convention (THINK C / CodeWarrior 68k):
# arguments pushed right to left, caller pops; 16-bit ints take 2 stack bytes, chars take 2 (value in
# the first byte), pointers and longs take 4. Results in D0.
# Types: void i8 u8 i16 u16 i32 u32 ptr
# Hand-written assembly routines use "regs": <seg> <off> regs <name>, C signature void name(Regs *r)
# (game/mzasm.h); every register and the CCR must come out exactly as the original leaves them.
#
# Options after the signature: d0=zext  the original leaves D0's upper bits zero (moveq / ext.l before return)
#                               nocheck  calls Toolbox routines with state outside emulated memory: not
#                                        checked call by call (the end-to-end comparison still covers it)
#                               ignore=d0,d1,a0,ccr  registers not compared: for a register-level routine,
#                                        ones its callers provably never read (a compiled callee left
#                                        them, or the caller restores / reloads them); for compiled C,
#                                        callee-saved ones the original clobbers through an assembly
#                                        helper. ignore=all: D0-D7, A0-A4 and the CCR (object handlers,
#                                        whose dispatcher restores everything else)
#                               both     a shared function that also handles Mazeworld Original's
#                                        version (per-game branches); it then runs at the paired address
#                               orig     Mazeworld Original's own function (fo_S<seg>_<off>, at
#                                        Original's address): runs for Original only
# <seg> <off> internal <name>: translated inside its callers only (its interface cannot be called from
#                               the harness, e.g. it jumps through a code pointer in A3)
#
